# مطبخ البيت (home-kitchen)

تطبيق شخصي لإدارة الطبخ المنزلي: مكتبة وصفات مرتبطة بـ OneNote، وتخطيط أسبوعي للوجبات، وقائمة مقاضي موحدة، ومهام تجهيز، ومفرزنات، ولانش بوكس.

## الحالة

**المرحلة 1 (مكتبة الوصفات) شبه مكتملة، وتنتظر وصول `recipes.json` الحقيقي.** يعمل الآن: المكتبة والبحث العربي، قراءة دفتر OneNote وإنشاء صفحات جديدة فيه (لا تعديل ولا حذف لصفحة موجودة أبدًا)، وضع الطبخ، الصور، سجل التجارب، الإصدارات السابقة واسترجاعها، التوسيم الجماعي، سلة المحذوفات، العمل دون إنترنت، والنسخ الاحتياطي الليلي إلى OneDrive مع الاستعادة منه (ولا يُنشر التطبيق إلا بعد نجاح اختبار استعادة تلقائي على قاعدة مؤقتة)، وتنزيل نسخة كاملة إلى الجهاز، وتعليم مهام التجهيز دون إنترنت. **المرحلة 2** فيها الآن الخطة الأسبوعية (2أ)، ومهام التجهيز و«الآن» (2د)، وطباعة الأسبوع (2هـ، تنتظر تجربتك على الجوال)؛ المقاضي (2ب و2ج) تنتظر `recipes.json`. والمرحلة 3 (تجارب الإطلاق: استعادة فعلية، جهازان، الوثائق) لم تبدأ. مشاركة الأخت أُلغيت (2026-11-14).

## التشغيل على الجهاز

يحتاج Node.js 22، والإصدار محدد في `.nvmrc`.

```bash
nvm use
npm install
npm run dev
```

ثم فتح http://localhost:5173

| الأمر | الوظيفة |
|---|---|
| `npm test` | تشغيل الاختبارات |
| `npm run typecheck` | فحص الأنواع |
| `npm run build` | بناء نسخة الإنتاج في `dist/` |

## الخط

IBM Plex Sans Arabic 1.1.0، أربعة أوزان (400 و500 و600 و700) بصيغة woff2 من الإصدار الرسمي `@ibm/plex-sans-arabic@1.1.0`. الملفات مطابقة لمستودع IBM وغير معدّلة، والترخيص SIL Open Font License 1.1 في `public/fonts/ibm-plex-sans-arabic/LICENSE.txt`.

## قواعد المستودع

- لا أسرار ولا مفاتيح API في المستودع. الإعدادات السرية تُحفظ في ملفات `.env` المستثناة من Git، أو في إعدادات الخادم.
- لا تعديل على دفتر OneNote الحقيقي قبل نجاح التجربة على دفتر تجريبي والموافقة الصريحة.
